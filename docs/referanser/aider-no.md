# aider.no – hva vi tok med oss

Kilde: https://aider.no/ + kulturkartleggingssiden

## Design
- Mørk blå hero med stjernemønster
- Store, tydelige knapper
- Seksjoner med tekst + bilde annenhver side
- Kontaktperson-kort med tittel, telefon, LinkedIn

## Innhold/struktur
- 4-stegs prosess: Undersøkelse → Analyse → Workshop → Handlingsplan
- «Basert på fakta, ikke synsing»
- Lead-quiz: 4 innledende spørsmål før hovedskjema
